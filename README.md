# CustomMob

`CustomMob` создаёт настроенных мобов с собственной логикой движения, ближних и дальних атак. Плагин запускает поведение мобов раз в тик, помечает созданные сущности через `PersistentDataContainer` и восстанавливает их обработку при загрузке чанков.

## Требования и зависимости

- Paper API `1.21.7-R0.1-SNAPSHOT`.
- `api-version: "1.21"`.
- Java 21.
- Обязательные зависимости (`depend`): отсутствуют.
- Необязательные зависимости (`softdepend`): отсутствуют.

Плагин использует Paper API. Совместимость с Spigot и другими ядрами в проекте не заявлена.

## Установка и сборка

### Установка

1. Соберите или скачайте `custom_mob.jar`.
2. Поместите файл в каталог `plugins/` сервера Paper.
3. Запустите сервер. Плагин создаст `plugins/CustomMob/config.yml` из встроенного шаблона.
4. При необходимости измените `config.yml` и выполните `/custommob reload`.

Плагин не использует SQLite, MySQL или другой внешний storage. Состояние текущих атак, снаряды, зоны и оглушения не сохраняются между перезапусками.

### Сборка из исходников

Для сборки нужен JDK 21 и Maven:

```shell
mvn clean package
```

Результат: `target/custom_mob.jar`.

## Команды и права (Permissions)

| Команда | Описание | Permission | По умолчанию |
| --- | --- | --- | --- |
| `/custommob spawn <тип> [игрок]` | Создаёт моба рядом с игроком. Если `игрок` не указан, команда использует позицию отправителя, если отправитель является игроком. | `rockfrost.admin` | `op` |
| `/custommob reload` | Перечитывает `config.yml` и обновляет настройки контроллера `harry_mono`. | `rockfrost.admin` | `op` |

Подкоманды и идентификаторы мобов поддерживают Tab completion. Для консоли укажите аргумент `[игрок]` с именем игрока онлайн.

## Типы мобов

| Идентификатор | Название в конфигурации | Поведение |
| --- | --- | --- |
| `pumpkin` | `Тыквитель` | Преследует игрока и атакует вблизи. |
| `pumpkin_soul` | `Тыквитель Душ` | Держит дистанцию и выпускает прямолинейные снаряды. |
| `pumpkin_brute` | `Тыквитель Брута` | Атакует вблизи; после смерти создаёт взрыв с уроном и эффектом тошноты. |
| `pumpkin_poison` | `Тыквитель Яда` | Атакует вблизи и накладывает яд на игрока. |
| `skelebass` | `СкелеБас` | Держит дистанцию и стреляет снарядами с отбрасыванием. |
| `dancebomber` | `ДенсБомбер` / `Безголовый ДенсБомбер` | Бросает бомбу по дуге, затем временно преследует цель и атакует вблизи. |
| `harry_mono` | `Гарри Моно` | Использует ближнюю атаку и случайно выбирает одну из спецатак: таран, масляная бомба, вращение или прыжок. |

Безопасную позицию для появления плагин ищет в радиусе от 2 до 5 блоков от исходной позиции. Моб должен иметь твёрдую опору, два свободных блока по высоте и не пересекаться с другими сущностями.

## Конфигурация

Основной файл: [`src/main/resources/config.yml`](src/main/resources/config.yml). Рабочая копия после запуска: `plugins/CustomMob/config.yml`.

Все настройки мобов находятся в секциях `mobs.<тип>`. Добавление новой секции само по себе не регистрирует новый тип: список идентификаторов задан в коде плагина.

### Общие параметры

- `entity-type` задаёт тип сущности Bukkit, например `ZOMBIE` или `SKELETON`.
- `custom-name`, `custom-name-normal`, `custom-name-headless` задают имена мобов. Для `harry_mono.custom-name` используется MiniMessage.
- `max-health` и `movement-speed` задают базовые характеристики.
- `detection-range` задаёт радиус поиска цели у мобов, которые используют этот параметр.
- `melee-range`, `melee-damage`, `melee-cooldown-ticks` управляют ближней атакой.
- `keep-distance` и `attack-cooldown-ticks` используются мобами с дистанционной атакой.

Значения с суффиксом `-ticks` указаны в серверных тиках: 20 тиков соответствуют одной секунде при 20 TPS. Параметры урона и здоровья используют единицы Minecraft.

### Дистанционные атаки и эффекты

- `projectile` задаёт максимальную дальность, скорость, радиус попадания и урон снаряда.
- `skelebass.projectile.knockback-strength` задаёт отбрасывание, а `pierce-entities` разрешает поражать несколько игроков одним снарядом.
- `pumpkin_brute.explosion` задаёт радиус, урон и параметры тошноты после смерти моба.
- `pumpkin_poison.poison-duration-ticks` и `poison-amplifier` задают длительность и уровень яда.

### `dancebomber`

- `normal-movement-speed`, `headless-movement-speed` и `headless-duration-ticks` управляют обычной и безголовой фазами.
- `keep-distance` и `throw-cooldown-ticks` задают дистанцию и интервал бросков.
- `bomb-projectile` задаёт материал `ItemDisplay`, строковый `custom-model-data-string`, `item-model`, скорость, гравитацию, дальность, радиус попадания, радиус взрыва, урон и отбрасывание.
- Взрыв поражает живые сущности, кроме бросившего бомбу моба, и не разрушает блоки.

### `harry_mono`

- `special-attack-interval-ticks` задаёт интервал после завершения спецатаки.
- `ram`, `oil-bomb`, `spin` и `jump` содержат параметры соответствующих спецатак.
- Поля `weight` в этих четырёх секциях задают относительную вероятность выбора атаки. Нулевой вес отключает атаку. Если все веса равны нулю, используется ближний бой.
- `zone-particle-period-ticks` задаёт период эффектов масляных зон и следа тарана.

`harry_mono` показывает BossBar `Байкер Гарри Моно` игрокам в радиусе 100 блоков. Игроки в режимах `CREATIVE` и `SPECTATOR` не становятся его боевыми целями.

### Звуки и частицы

Секции `sounds.<событие>` и `particles.<событие>` настраивают эффекты событий мобов. Звуки поддерживают имена Bukkit и namespaced keys. Для звука `skelebass` в стандартном конфиге используется `quack_mob:skelebass.attack`, поэтому соответствующий звук требует ресурс-пак с этим ресурсом. Плагин ресурс-пак не раздаёт.

В списках частиц используются `type`, `count`, `offset: [x, y, z]`, `extra` и необязательный `y-offset`. Для `DUST_COLOR_TRANSITION` дополнительно задаются `from-color`, `to-color` и `scale`.

После изменения настроек выполните `/custommob reload`. Новые `entity-type`, имена и `max-health` применяются при создании мобов. Перезагрузка не пересоздаёт существующие сущности.

## Java API

Главный класс плагина: `com.example.RockFrostPlugin`.

```java
public LivingEntity spawnMob(String mobId, Location location)
```

Метод нужно вызывать в основном потоке сервера. `mobId` не зависит от регистра и должен соответствовать одному из идентификаторов в разделе [Типы мобов](#типы-мобов). Метод возвращает созданную сущность или `null`, если идентификатор неизвестен, позиция некорректна либо безопасное место не найдено.

Пример вызова из другого плагина:

```java
import com.example.RockFrostPlugin;
import org.bukkit.Location;
import org.bukkit.entity.LivingEntity;
import org.bukkit.plugin.java.JavaPlugin;

RockFrostPlugin customMob = JavaPlugin.getPlugin(RockFrostPlugin.class);
LivingEntity mob = customMob.spawnMob("harry_mono", location);
if (mob == null) {
    getLogger().warning("Не удалось создать harry_mono");
}
```

Плагин не регистрирует публичные API-события и не содержит `PlaceholderExpansion`.
