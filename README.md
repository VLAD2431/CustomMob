# CustomMob

CustomMob создаёт мобов с собственной логикой движения, ближними и дальними атаками и боссом Гарри Моно. Администратор вызывает мобов командой, другой плагин может использовать Java API; автоматического запуска волн в текущем коде нет.

## Требования и зависимости

- Java 21 или новее; для сборки нужен JDK 21 или новее и Maven.
- Paper с API 1.21.7: в `pom.xml` указана зависимость `paper-api:1.21.7-R0.1-SNAPSHOT`, в `plugin.yml` указано `api-version: "1.21"`. Совместимость с более ранними выпусками 1.21 из этой декларации не следует.
- Плагин использует Paper API для целей мобов, поиска пути и событий отбрасывания. Spigot не является целевой платформой.
- Обязательных (`depend`) и опциональных (`softdepend`) плагинов в `plugin.yml` нет.

Для звука `quack_mob:skelebass.attack` и пользовательской модели бомбы нужен resource pack с соответствующими ресурсами. Плагин не раздаёт resource pack игрокам.

## Установка и сборка

Сборка из корня проекта:

```shell
mvn clean package
```

Итоговый файл: `target/custom_mob-1.0.0.jar`.

1. Поместите `.jar` в каталог `plugins/` сервера.
2. Запустите сервер. При первом включении плагин создаст `plugins/CustomMob/config.yml`.
3. Настройте мобов в этом файле и выполните `/custommob reload`.
4. Для проверки создайте моба: `/custommob spawn pumpkin`.

Плагин помечает мобов через `PersistentDataContainer` и восстанавливает управление помеченными сущностями при включении и загрузке чанков. Временные состояния боя, снаряды и зоны Гарри Моно не сохраняются между перезапусками или выгрузками сущностей.

## Команды и права (Permissions)

| Команда | Описание | Permission | По умолчанию |
| --- | --- | --- | --- |
| `/custommob spawn <тип> [игрок]` | Создать моба рядом с указанным игроком; без аргумента использовать позицию отправителя-игрока | `rockfrost.admin` | `op` |
| `/custommob reload` | Перечитать `config.yml` и обновить настройки контроллера Гарри Моно | `rockfrost.admin` | `op` |

Для консоли аргумент `[игрок]` обязателен: укажите точное имя игрока онлайн. Если имя не найдено, отправитель-игрок создаёт моба рядом с собой, а консоль не создаёт моба. Поиск места появления проверяет горизонтальные смещения от 2 до 5 блоков и вертикальные от −2 до +1 блока относительно исходной позиции; если свободного места с твёрдой опорой нет, создание не состоится.

Команда дополняет подкоманды и идентификаторы мобов через Tab.

### Типы мобов

| Идентификатор `<тип>` | Название в стандартном конфиге | Механика |
| --- | --- | --- |
| `pumpkin` | Тыквитель | Преследует игрока и атакует вблизи |
| `pumpkin_soul` | Тыквитель Душ | Держит дистанцию и выпускает прямолинейные снаряды |
| `pumpkin_brute` | Тыквитель Брута | Атакует вблизи; через 20 тиков после смерти наносит урон по области и накладывает игрокам тошноту |
| `pumpkin_poison` | Тыквитель Яда | Атакует вблизи и накладывает яд при нанесении урона игроку |
| `skelebass` | СкелеБас | Держит дистанцию, стреляет снарядами с отбрасыванием; не стреляет во время отступления |
| `dancebomber` | ДенсБомбер / Безголовый ДенсБомбер | Бросает бомбу по дуге, затем временно переходит к преследованию и ближним атакам |
| `harry_mono` | Гарри Моно | Чередует ближний бой со случайно выбранными спецатаками: таран, масляная бомба, вращение и прыжок |

## Конфигурация

Исходный конфиг находится в [`src/main/resources/config.yml`](src/main/resources/config.yml). Все настройки относятся к секциям `mobs.<тип>`; добавление произвольной секции не регистрирует новый тип моба.

Время с суффиксом `-ticks` задаётся в серверных тиках: при 20 TPS одна секунда равна 20 тикам. Расстояния задаются в блоках, урон и здоровье в единицах Minecraft: 2 единицы соответствуют одному сердцу. Уровень эффекта `*-amplifier: 0` означает первый уровень.

### Базовые параметры и атаки

| Параметры / секция | Назначение |
| --- | --- |
| `entity-type` | Тип сущности Bukkit (`ZOMBIE`, `SKELETON` и т. п.). Нужен тип, который реализует `Mob` |
| `custom-name` | Имя моба. Для `harry_mono` поддерживает MiniMessage; у `dancebomber` используются `custom-name-normal` и `custom-name-headless` |
| `max-health`, `movement-speed` | Максимальное здоровье при создании и базовый атрибут скорости передвижения |
| `detection-range` | Радиус поиска цели у тыквенных мобов и Гарри Моно. СкелеБас и ДенсБомбер ищут цель в фиксированном радиусе 32 блока |
| `melee-range`, `melee-damage`, `melee-cooldown-ticks` | Дистанция, урон и задержка ближних атак у соответствующих мобов. У Гарри Моно эти параметры находятся в `melee.range`, `melee.damage`, `melee.cooldown-ticks` |
| `keep-distance`, `attack-cooldown-ticks` | Желаемая дистанция и интервал выстрелов у `pumpkin_soul` и `skelebass` |
| `projectile` | Дальность (`max-distance`), скорость (`speed-per-tick`), расширение хитбокса цели (`hitbox-radius`) и урон снаряда |
| `skelebass.projectile.knockback-strength`, `skelebass.projectile.pierce-entities` | Сила отбрасывания и возможность поразить несколько игроков одним снарядом. Твёрдый блок останавливает снаряд |
| `pumpkin_brute.explosion` | Радиус и урон посмертного взрыва, длительность и уровень тошноты |
| `pumpkin_poison.poison-duration-ticks`, `pumpkin_poison.poison-amplifier` | Длительность и уровень яда |

Пути в последних трёх строках таблицы указаны относительно `mobs`.

Имена над мобами скрыты. BossBar Гарри Моно показывает здоровье игрокам в радиусе 100 блоков; его заголовок `Байкер Гарри Моно` задан в коде и не зависит от `custom-name`. Гарри Моно не выбирает игроков в Creative и Spectator боевыми целями.

### ДенсБомбер

В `mobs.dancebomber`:

- `normal-movement-speed` и `headless-movement-speed` задают скорость двух фаз; `headless-duration-ticks` задаёт длительность безголовой фазы.
- `keep-distance` управляет дистанцией обычной фазы, `throw-cooldown-ticks` задаёт интервал бросков.
- `bomb-projectile.speed`, `gravity`, `max-distance`, `hitbox-radius` управляют полётом и столкновениями бомбы.
- `bomb-projectile.explosion-radius`, `explosion-damage`, `explosion-knockback` задают область, урон и отбрасывание взрыва. Бомба поражает живые сущности, кроме бросившего её моба, и не разрушает блоки.
- `bomb-projectile.material` задаёт материал предмета в `ItemDisplay`, по умолчанию `WOODEN_HOE`.
- `bomb-projectile.custom-model-data-string` записывает строку в компонент CustomModelData, по умолчанию `densbomb`. Это строка, а не числовой CustomModelData.
- `bomb-projectile.item-model` задаёт ключ модели предмета, например `namespace:model`; пустая строка оставляет модель без изменения. Для ключа без namespace код использует `minecraft:`.

### Гарри Моно

В `mobs.harry_mono`:

- `special-attack-interval-ticks` задаёт интервал после завершения спецатаки. В этот период босс преследует цель и атакует вблизи.
- `ram.weight`, `oil-bomb.weight`, `spin.weight`, `jump.weight` задают относительные вероятности атак: вес / сумма положительных весов. Нулевой вес отключает атаку; если все веса нулевые, остаётся ближний бой. Повторы одной атаки разрешены.
- `ram` управляет подготовкой, скоростью и длиной тарана, уроном, отбрасыванием и опасным следом (`trail-*`). При пересечении собственной масляной зоны босс поджигает игроков в ней и удаляет зону.
- `oil-bomb` задаёт полёт бомбы, радиус и срок жизни масляной зоны. `initial-damage` наносится один раз каждому вошедшему игроку для каждой зоны; `slow-*` задают обновление замедления, а `burn-duration-ticks` задаёт длительность горения при поджоге тараном.
- `spin` задаёт подготовку и длительность вращения, радиус, притяжение и периодический урон. Притяжение начинается через 20 тиков активной фазы; во время активного вращения босс не получает урон и отбрасывание.
- `jump` задаёт подготовительную дистанцию, тайм-аут подготовки, скорости прыжка, предельное время полёта, радиус и урон приземления. `stun-duration-ticks` задаёт оглушение: блокировку перемещения, атак и взаимодействий. Телепортация, смерть и выход игрока снимают оглушение.
- `zone-particle-period-ticks` задаёт период эффектов масляных зон и следа тарана.

### Звуки и частицы

Секции `sounds.<событие>` и `particles.<событие>` относятся к событиям конкретного моба, например `shoot`, `projectile-trail`, `explosion`, `ram-start` или `jump-land`. Используйте имена событий из конфига и обработчиков; произвольное имя не добавляет новый эффект.

- У звука `sound` принимает имя Bukkit (`ENTITY_GENERIC_EXPLODE`) или namespaced key (`minecraft:block.note_block.bass`). `category`, `volume`, `pitch` задают категорию, громкость и высоту.
- `max-distance` ограничивает расстояние до слушателя, по умолчанию 64 блока. `repeat` повторяет воспроизведение в рамках одного вызова, без временного интервала.
- Список частиц содержит `type`, `count`, `offset: [x, y, z]`, `extra` и необязательный `y-offset`.
- Для `DUST_COLOR_TRANSITION` используются `from-color`, `to-color` (RGB) и `scale`; для частиц с данными типа `Color`, например `FLASH`, используется `color`. Частицы с `BlockData` берут материал опоры, а при её отсутствии используют `STONE`.

### Применение изменений

После редактирования выполните `/custommob reload`. Новые `entity-type`, `custom-name` и `max-health` применяются при создании моба; перезагрузка не пересоздаёт существующие сущности. Имена фаз ДенсБомбера обновляются при переключении фазы. Скорость и параметры обычных атак код читает во время работы. Текущие спецатаки, бомбы и зоны Гарри Моно сохраняют снимок настроек, с которым начались; последующие спецатаки используют новые настройки.

## Java API

Главный класс: `com.example.RockFrostPlugin`. Публичный метод:

```java
public LivingEntity spawnMob(String mobId, Location location)
```

Вызывайте его в основном потоке сервера. Метод принимает один из перечисленных идентификаторов без учёта регистра, ищет безопасную позицию рядом с `location` и возвращает созданную сущность. При неизвестном ID, некорректной позиции или невозможности создания он возвращает `null`.

Пример внутри другого плагина, который компилируется с CustomMob в classpath:

```java
import com.example.RockFrostPlugin;
import org.bukkit.entity.LivingEntity;
import org.bukkit.plugin.java.JavaPlugin;

// Основной поток сервера; location имеет тип org.bukkit.Location.
RockFrostPlugin customMob = JavaPlugin.getPlugin(RockFrostPlugin.class);
LivingEntity mob = customMob.spawnMob("harry_mono", location);
if (mob == null) {
    getLogger().warning("Не удалось создать harry_mono");
}
```

Для прямого обращения к классу добавьте `depend: [CustomMob]` в `plugin.yml` вызывающего плагина, чтобы он загружался после CustomMob.
